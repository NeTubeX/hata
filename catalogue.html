📘 Catalogue d'Utilisation

Système de Gestion de Scolarité — NeTubeX SARL — Année 2026-2027
👨‍🏫 Espace Professeur
ÉTAPE 1

🔑 Connexion

Sélectionnez votre nom et entrez votre code d'accès à 6 chiffres.

💡 Astuce : Contactez la direction si vous avez oublié votre code.
ÉTAPE 2

📝 Créer une fiche

Remplissez Cours, Classe et Option, puis cliquez sur le bouton vert.

✨ Important : Les élèves sont importés automatiquement depuis la comptabilité.
ÉTAPE 3

✏️ Saisie des notes

Cliquez dans une cellule pour entrer une note. Les totaux se calculent automatiquement.

🎯 Conseil : Utilisez la barre de recherche pour filtrer les élèves par nom.
ÉTAPE 4

⚡ Correction Rapide

Utilisez le pavé numérique pour noter rapidement chaque élève.

🔄 Navigation : Utilisez "Préc" et "Suiv" pour passer d'un élève à l'autre.
ÉTAPE 5

📄 Exporter en PDF

Générez un bulletin complet ou un relevé individuel.

💾 Astuce : Les PDF sont téléchargés automatiquement.
ÉTAPE 6

🕐 Mon Horaire

Visualisez votre emploi du temps. Cliquez sur un créneau pour voir les détails.

📌 Navigation : Utilisez "Hier" et "Demain" pour consulter les autres jours.
📋 Espace Titulaire
ÉTAPE 1

⚙️ Configuration

Entrez votre nom et sélectionnez les classes dont vous êtes responsable.

📌 Important : Cochez "TOUTES" pour les cours d'ensemble.
ÉTAPE 2

📋 Consultation

Visualisez les fiches de vos classes. Utilisez les filtres par période.

🔒 Mode lecture : Les notes sont consultables mais non modifiables.
ÉTAPE 3

📊 Statistiques

Consultez les chiffres clés de vos classes : effectif total, fiches actives, répartition.

📄 Export : Téléchargez un rapport statistique en PDF.
ÉTAPE 4

🔍 Recherche

Entrez un nom pour obtenir le relevé de notes complet de l'élève.

📄 Export : Téléchargez le relevé individuel en PDF.
