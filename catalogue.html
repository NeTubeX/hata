📋 PROCÉDURE :
  1. Étape 1 : Choisir son nom dans la liste déroulante des professeurs
  2. Étape 2 : Saisir son code d'accès (4 chiffres) dans le champ prévu
  3. Étape 3 : Cliquer sur le bouton "SE CONNECTER"
  4. Étape 4 : En cas d'erreur, un message "Code incorrect" s'affiche
📖 GUIDE COMMENTÉ - ÉTAPE 1

1. Sélection du professeur :
La liste déroulante affiche tous les professeurs enregistrés.
Chaque professeur est identifié par un numéro (01, 02, 03...) et son nom complet.
Exemple : "01. Prof. KASONGO Jean"

2. Saisie du code :
Le code d'accès est un nombre à 4 chiffres.
Les caractères sont masqués par des points (●) pour la sécurité.
Exemple : "1234" s'affiche "● ● ● ●"

3. Bouton de connexion :
Une fois les champs remplis, cliquez sur "SE CONNECTER".
Si les identifiants sont corrects, l'accès à l'application est accordé.
Si le code est incorrect, un message d'erreur s'affiche.

4. Navigation après connexion :
Après une connexion réussie, l'utilisateur accède à :
- L'Espace Professeur (gestion des fiches, cotation, correction, etc.)
- L'Espace Titulaire (consultation des fiches des classes responsables)
